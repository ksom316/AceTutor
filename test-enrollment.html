🎓 AceTutor Enrollment Testing Guide

⚠️ Prerequisites:
  • Dev server running at http://localhost:8080
  • OpenRouter API key configured ✅
  • Supabase connected ✅
  • Clear browser cache before testing

📋 Test Checklist

1. Test Logged-Out State
✓ Expected: "View course" buttons on all courses
  1. Open http://localhost:8080 in incognito window
  2. Verify header shows "Sign in" and "Sign up" buttons
  3. Scroll to course cards
  4. Each course should show only "View course" button
  5. Click "View course" → should navigate to course detail
  6. On detail page, large "Enroll now" button should redirect to /login
2. Test Login Flow
✓ Expected: Demo accounts work, redirect to onboarding/dashboard
  1. Go to http://localhost:8080/login
  2. Click "Continue with Google"
  3. Select Jane Doe demo account
  4. Should redirect to VARK onboarding (first time) or dashboard (returning)
  5. Complete VARK if shown (answer ~16 questions)
3. Test Enrollment - Not Enrolled State
✓ Expected: "Enroll" + "View" buttons
  1. Navigate to http://localhost:8080/courses
  2. Find a course you haven't enrolled in
  3. Should show "Enroll" (primary) + "View" (ghost) buttons
  4. Click "Enroll"
  5. Should see toast: "Enrolled — find it under My Courses"
  6. Button should change to "✓ Enrolled" badge + "Continue"
4. Test Enrollment - Already Enrolled State
✓ Expected: "Enrolled" badge + "Continue" button
  1. After enrolling, stay on /courses
  2. The enrolled course should now show:
    • Green "✓ Enrolled" badge on gradient thumbnail
    • "Continue" button (with play icon)
  3. Click "Continue" → navigate to course detail
  4. On detail page, no "Enroll" button (already enrolled)
5. Test Course Detail Page - Enrolled
✓ Expected: Full access, AI features, quiz buttons
  1. Go to an enrolled course detail page
  2. Should see:
    • AI Course Chat section (ask questions)
    • Module/topic accordion with "Start Quiz" buttons
    • Progress analytics (if you've taken quizzes)
    • "Generate AI Quiz" option per module
  3. Try asking AI a question (e.g., "What is this course about?")
  4. Should get response from Wikipedia-based AI tutor
6. Test AI Quiz Generation
✓ Expected: 10 multiple-choice questions, save results
  1. On course detail, expand a module
  2. Click "Generate AI Quiz" button
  3. Should show loading, then quiz dialog with 10 questions
  4. Answer all questions
  5. Click "Finish Quiz"
  6. Should show score (saved to performance)
  7. Results should appear in analytics section
7. Test My Courses Page
✓ Expected: All enrolled courses listed
  1. Click sidebar → "My Courses"
  2. Should list all courses you enrolled in
  3. Each shows progress percentage (if quizzes taken)
  4. Click any course → navigate to detail
8. Test Dashboard Integration
✓ Expected: Enrolled courses, recent activity, recommendations
  1. Go to Dashboard
  2. Should show:
    • Your enrolled courses
    • Recent quiz attempts
    • Overall progress
    • Personalized study recommendations (if performance data exists)
9. Test Multiple Enrollments
✓ Expected: Each course tracks independently
  1. Enroll in 2-3 different courses
  2. Take quizzes in different courses
  3. Verify each course shows its own progress
  4. Dashboard should aggregate all performance
10. Test Logout & Re-login
✓ Expected: Enrollments persist
  1. Click profile → "Sign out"
  2. Sign back in with same demo account
  3. Go to "My Courses"
  4. All previous enrollments should still be there
  5. Quiz history should be preserved

🐛 Common Issues & Fixes

Issue: "Sign in to enroll" error
➜ Auth state not loading. Clear localStorage and refresh.
Issue: Enroll button doesn't change after clicking
➜ Query invalidation issue. Check browser console for errors.
Issue: AI quiz generation fails
➜ OpenRouter API key not loaded. Restart dev server after adding key.
Issue: "OAuth state not found"
➜ Use demo accounts instead, or configure Supabase Google OAuth.

✅ Success Criteria

  • ✓ Logged-out users see "View course"
  • ✓ Logged-in users see "Enroll" for new courses
  • ✓ Enrollment adds "✓ Enrolled" badge immediately
  • ✓ Enrolled courses show "Continue" button
  • ✓ AI chat works (Wikipedia-based responses)
  • ✓ AI quiz generates 10 questions and saves results
  • ✓ My Courses page lists all enrollments
  • ✓ Dashboard shows aggregated progress
  • ✓ Enrollments persist after logout/login

🚀 Quick Start

Fastest test path:

  1. Open http://localhost:8080/login
  2. Click "Continue with Google" → Select "Jane Doe"
  3. Complete VARK onboarding (or skip if returning user)
  4. Go to "Courses" in sidebar
  5. Click "Enroll" on any course
  6. Verify it changes to "Enrolled" badge + "Continue"
  7. Click "Continue" → try AI chat and quiz generation
